## Signing

zlrd uses [CLA Assistant](https://github.com/contributor-assistant/github-action).
The first time you open a pull request, a bot comments on it with a link and a
short instruction. Reply on the pull request with:

```
I have read the CLA Document and I hereby sign the CLA
```

That records your signature against your GitHub account. You will not be asked
again for later pull requests.

If the bot is not running for some reason, say so in the pull request and the
Maintainer will record your acceptance manually.
